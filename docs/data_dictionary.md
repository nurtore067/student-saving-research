# Словарь столбцов CSV

Единица наблюдения: один синтетический персонаж. 330 строк, 63 столбца. Все деньги в KZT. UTF-8 с BOM, разделитель — запятая, десятичный разделитель — точка. Русские тексты заключаются в кавычки по правилам CSV. Пустое значение предусмотрено только для необязательного комментария. Данные полные по замыслу тестового набора, а не по факту реального сбора.

## Идентификаторы, происхождение и распределение

| Столбец | Тип / значения | Значение |
|---|---|---|
| `participant_id` | Текст, SYN_0001…SYN_0330 | Уникальный вымышленный идентификатор. Не номер человека и не номер группы |
| `data_origin` | `synthetic` | Постоянная маркировка синтетического происхождения |
| `generation_method` | `persona_rules_v1.0` | Версия правил генерации |
| `group` | A / B / C | Случайно присвоенная группа; по 110 записей |
| `consent` | 1 | Смоделированное прохождение проверки согласия для совместимости с Task 2 |
| `consent_is_simulated` | 1 | Флага реального добровольного согласия здесь нет |
| `is_student_almaty` | 1 | Персонаж по сценарию учится в университете Алматы |

## Исходные сведения и бюджет

| Столбец | Тип / значения | Значение |
|---|---|---|
| `age` | Целое 18–24 | Полный возраст |
| `study_year` | Целое 1–6 | Курс; ограничен возрастом в генераторе |
| `employment_status` | none / part_time / full_time / freelance | Не работает / неполная занятость / полная / отдельные заказы |
| `housing` | parents / dorm / shared_rent / relatives | С родителями / общежитие / совместная аренда / у родственников |
| `situation_code` | Текст, 24 категории | Внутренний код жизненной ситуации; полный перечень `SITUATIONS` в генераторе |
| `monthly_work_income_kzt` | Целое ≥0 | Доход от работы и заказов за последний полный месяц |
| `monthly_scholarship_kzt` | Целое ≥0 | Стипендия; значения — сценарные допущения, не актуальные тарифы |
| `monthly_family_support_kzt` | Целое ≥0 | Полученная денежная помощь семьи |
| `monthly_income_kzt` | Целое ≥0 | Сумма трёх предыдущих источников |
| `income_irregular` | 0 / 1 | Нет / есть заметная нерегулярность дохода по сценарию |
| `monthly_housing_kzt` | Целое ≥0 | Личные обязательные расходы на жильё |
| `monthly_living_kzt` | Целое ≥0 | Остальные базовые расходы, кроме жилья, помощи семье и рассрочки |
| `monthly_family_transfer_kzt` | Целое ≥0 | Исходящие обязательные переводы семье; отличаются от полученной помощи |
| `monthly_installment_kzt` | Целое ≥0 | Платёж по уже существующей рассрочке; не гипотетические наушники |
| `has_installment_debt` | 0 / 1 | Существующая рассрочка. В этой симуляции 1 тогда и только тогда, когда месячный платёж >0 |
| `monthly_essential_kzt` | Целое ≥0 | Жильё + базовые расходы + помощь семье + текущие платежи |
| `monthly_balance_kzt` | Целое, может быть <0 | Доход минус обязательные расходы; сохраняет дефицит |
| `monthly_available_kzt` | Целое ≥0 | max(0, monthly_balance_kzt). Не остаток после всех необязательных трат |
| `monthly_shortfall_kzt` | Целое ≥0 | max(0, −monthly_balance_kzt). Источник покрытия дефицита не смоделирован |
| `monthly_other_spending_kzt` | Целое ≥0 | Прочие расходы после обязательных платежей |
| `last_month_saved_kzt` | Целое ≥0 | Новые сбережения за этот месяц, не весь накопленный запас |
| `saving_frequency` | Целое 1–5 | Никогда / редко / иногда / часто / каждый месяц, за последние 6 месяцев |
| `budget_tracking` | Целое 1–5 | Не ведёт / проверяет остаток / примерный бюджет / записывает большинство расходов / регулярно планирует |
| `saving_barrier` | Категория | Основное препятствие; коды ниже |

Проверяемая бухгалтерская связь внутри сценария:

`income + shortfall = essential + other_spending + last_month_saved`.

Это запись величины непокрытого дефицита, а не утверждение, что он был фактически профинансирован. Нулевые новые накопления в последнем месяце не исключают прошлых накоплений и прежней привычки копить.

Коды препятствий: `not_enough_income` — не хватает дохода; `unexpected_costs` — неожиданные расходы; `unstable_income` — нестабильный доход; `competing_goals` — несколько целей; `impulse_spending` — спонтанные покупки; `no_regular_plan` — нет регулярного плана; `none` — ничего из перечисленного.

## Воздействие и ответы

| Столбец | Тип / значения | Значение |
|---|---|---|
| `stimulus_id` | Текст | Версия карточки: total_generic_v2 / installment_generic_v2 / installment_personalized_rule_preview_v2 |
| `price_primary_text` | Текст | Крупный заголовок цены; акцент на total в A и на installment в B/C |
| `price_secondary_text` | Текст | Второй ценовой показатель; условия одинаковы во всех группах |
| `guidance_method` | generic_fixed_text / rule_based_personalized_preview | Общая подсказка A/B или персонализированный алгоритмический preview C |
| `guidance_text_ru` | Текст | Полный текст конкретной подсказки; сведения о цене и общий текст карточки описаны в анкете |
| `goal_attainability_pre` | Целое 1–7 | Достижимость цели до карточки; 1 = Совсем недостижима, 7 = Полностью достижима |
| `goal_attainability_post` | Целое 1–7 | Та же оценка после карточки |
| `saving_intention_pre` | Целое 1–7 | Намерение отложить на цель в следующий месяц до карточки; 1 = Совсем маловероятно, 7 = Очень вероятно |
| `saving_intention_post` | Целое 1–7 | То же после карточки |
| `purchase_intention_post` | Целое 1–7 | Намерение купить показанные наушники; те же якоря вероятности |
| `total_cost_estimate_kzt` | Целое ≥0 | Ответ персонажа о полной стоимости наушников. Верно 24 000; возможны ошибки |
| `confusion_comment_ru` | Текст или пусто | Необязательный смоделированный комментарий о непонятной информации |
| `simulated_response_reason_ru` | Текст | Служебное объяснение реакции персонажа. Не ответ на отдельный вопрос формы |
| `reaction_label` | positive / neutral / negative | Знак изменения достижимости; это не общий рейтинг помощника |
| `goal_change` | Целое −6…6 | goal_attainability_post − goal_attainability_pre |
| `saving_intention_change` | Целое −6…6 | saving_intention_post − saving_intention_pre |
| `price_comprehension_correct` | 0 / 1 | 1, если ответ о цене равен 24 000 |

## Порядок анализа

Первичный показатель по исходной структуре Task 2: разность средних `goal_change` между C и B. Вторичный: разность средних `purchase_intention_post` между B и A. RQ1: связь исходной достижимости с исходным намерением копить. Ни один показатель в этом CSV не оценивает эффект на реальных людях.

Для моделей, в которых нужны только исходные ковариаты, не подставляйте post-ответы, изменения, понимание цены после карточки или служебные объяснения. Внутренние `persona_*` доступны только симулятору и не присутствуют в настоящей анкете. Не сравнивайте A/C как изолированный эффект подсказки: одновременно меняется акцент цены.
